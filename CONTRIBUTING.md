# Contributing to AltaStata

Thank you for your interest in contributing to AltaStata! We welcome bug reports, documentation improvements, feature suggestions, and code contributions.

---

## 1. How to Report Issues & Provide Feedback

- **Bug reports & feature requests**: Open an issue at [GitHub Issues](https://github.com/AltaStata/sovereign-data-fabric/issues/new). Please include your release version / tag (`vYYYY.MM.DD` or Python wheel version), OS, JDK, storage backend, and relevant logs (with credentials redacted).
- **Security vulnerabilities**: Do **not** open a public issue. See [SECURITY.md](SECURITY.md) for instructions on submitting private security reports.
- **Licensing & commercial inquiries**: Email `contact@altastata.com`.

---

## 2. Code Contributions & Pull Requests

Before submitting a Pull Request (PR), please ensure that:

1. **You own the code**: You are legally entitled to grant the licenses described in the Contributor License Agreement below (either you wrote the code or have written permission from your employer/copyright holder).
2. **Build and tests pass**: Follow [DEVELOPERS_GUIDE.md](docs/guides/DEVELOPERS_GUIDE.md) to build and run test suites locally.
3. **No credentials**: Ensure no secrets, keys, credentials, or private test tokens are committed.
4. **CLA Agreement**: By submitting a pull request or code patch to this repository, you agree to the **AltaStata Contributor License Agreement (CLA)** below.
