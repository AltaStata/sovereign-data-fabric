AltaStataChunkedOutputStream 

class AltaStataChunkedOutputStream extends OutputStream

Safe, high-performance chunked OutputStream for writing secure encrypted AltaStata cloud files.

It transparently splits output data into standard size chunks, encrypts each chunk on the fly using AES-GCM, signs metadata envelopes, and uploads them to the configured cloud storage. Includes support for append operations by dynamically reading, decrypting, appending, and rewriting the last chunk.
