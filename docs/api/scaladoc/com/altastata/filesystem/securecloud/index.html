    Core implementation of the AltaStata secure file system model.

    Core implementation of the AltaStata secure file system model.

    This class serves as the primary integration point for managing cloud files, handling secure file metadata, user identity verification (RSA/PQC), and coordinating cryptographic operations across supported cloud providers.

    It extends FileSystemModel for standard file operations and mixes in SecureCloudOperations to handle chunked encryption, compression, and data transfer.
